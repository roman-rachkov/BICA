## Ключевые концепции

1. **Бикамеральное мышление** — диалог между Наблюдателем и Исполнителем
2. **Внутренняя мотивация** — 5 драйверов (любопытство, безопасность, социальность, достижение, комфорт)
3. **Эмоциональная модуляция** — VAD-вектор влияет на параметры генерации
4. **Формирование личности** — привычки закрепляются через подкрепление
