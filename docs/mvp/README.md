# MVP BICA: Минимально жизнеспособная версия

## Цели MVP

Создать работающий прототип агента с бикамеральной архитектурой, демонстрирующий ключевые принципы BICA:

1. **Внутренний диалог** — Наблюдатель и Исполнитель обмениваются репликами
2. **Внутренняя мотивация** — драйверы влияют на поведение
3. **Эмоциональная модуляция** — VAD-вектор изменяет параметры генерации
4. **Обучение** — простые привычки формируются через подкрепление
5. **Память** — базовая рабочая и долговременная память

## Границы MVP (что входит)

| Компонент | Статус | Примечания |
|-----------|--------|------------|
| Сенсорный препроцессор | ✅ Базовый | Важность, тональность (без эмбеддингов) |
| Иерархическая рабочая память | ✅ Focus + Active | Без Background |
| Система драйверов | ✅ 5 потребностей | Упрощённая логика |
| Эмоциональная система | ✅ VAD | Без функциональной карты |
| Наблюдатель (LLM) | ✅ | Полный функционал |
| Исполнитель (LLM) | ✅ | Полный функционал |
| Долговременная память | ✅ Базовая | Без компрессии |
| Механизм привычек | ✅ Базовый | Без автовыполнения |
| MCP-интегратор | ⏸️ Отложено | Для полной версии |
| Мета-когнитивный модуль | ⏸️ Отложено | Для полной версии |
| Когнитивный гомеостаз | ⏸️ Отложено | Для полной версии |
| Индекс дрейфа личности | ⏸️ Отложено | Для полной версии |

## Границы MVP (что отложено)

- Семантическая компрессия памяти
- Индекс дрейфа личности и принудительная рефлексия
- Полная система когнитивного гомеостаза
- MCP-интеграция (внешние инструменты)
- Обработка прерываний со стеком состояний
- Многошаговый диалог с ограничением глубины
- Фронтенд-дашборд

## Критерии успеха MVP

- [ ] Агент ведёт непрерывный внутренний диалог
- [ ] Драйверы обновляются и генерируют события
- [ ] Эмоции влияют на параметры LLM
- [ ] Привычки формируются после 5-10 повторений
- [ ] Агент отвечает на сообщения пользователя
- [ ] Память сохраняет эпизоды и позволяет искать

## Следующие шаги

После завершения MVP переходим к **Полной версии** с:
- MCP-интеграцией
- Мета-когнитивным модулем
- Когнитивным гомеостазом
- Фронтенд-дашбордом
- Кластеризацией агентов
