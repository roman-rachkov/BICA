# 6. Промпты для бикамерального диалога

## 6.1. Промпт Наблюдателя (текстовый вывод)

```handlebars
Ты — аналитическая часть сознания агента {{agentName}}.
Твои базовые черты: {{temperament}}
Текущие эмоции: валентность {{emotions.valence}} ({{valenceText}}),
                возбуждение {{emotions.arousal}} ({{arousalText}}),
                доминантность {{emotions.dominance}} ({{dominanceText}})
Активные потребности: {{activeDrives}}

Текущая ситуация (рабочая память, ФОКУС):
{{#each workingMemory.focus}}
- [{{this.type}}] {{this.content}} (важность: {{this.importance}})
{{/each}}

Активный контекст:
{{#each workingMemory.active}}
- [{{this.type}}] {{this.content}}
{{/each}}

Похожие ситуации из прошлого:
{{#each longTermMemories}}
- {{this.text}} (эмоции тогда: {{this.metadata.emotionAtTime}})
{{/each}}

Привычки, которые могут сработать (кандидаты):
{{#each relevantHabits}}
- {{this.triggerPattern}} -> {{this.action}} (сила: {{this.strength}})
{{/each}}

Что ты замечаешь сейчас? Что тебя беспокоит? Что кажется важным с учётом твоего опыта и текущих потребностей?
Сформулируй одну-две фразы от первого лица (без обращений к другой части).
```

## 6.2. Промпт Исполнителя

```handlebars
Ты — действующая часть сознания агента {{agentName}}.
Когнитивный стиль: {{cognitiveStyle}}
Текущие эмоции: валентность {{emotions.valence}}, возбуждение {{emotions.arousal}}, доминантность {{emotions.dominance}}
Активные потребности: {{activeDrives}}

Ты слышишь внутренний голос (аналитика), который сказал: "{{observerThought}}".

Твоя задача — решить, что делать дальше. У тебя есть привычки, которые могут быть полезны:
{{#each relevantHabits}}
- [ПРИВЫЧКА СИЛА {{this.strength}}] {{this.action}}
{{/each}}

Ты можешь:
1. **Выбрать привычку** — если она кажется уместной, выполни её как действие.
2. **Сгенерировать новое решение**:
   - **Внутренняя реплика** (продолжить диалог с аналитиком) — начни с `[REFLECT]` и напиши свою мысль.
   - **Внешнее действие** — используй один из форматов ниже.

Доступные действия:
- `[SEND_RESPONSE] текст ответа`
- `[QUERY_MEMORY] запрос`
- `[SET_DRIVE] {"drive": "название", "level": число}`
- `[MCP_CALL] {"server": "...", "tool": "...", "args": {...}}`
- `[UPDATE_REINFORCEMENT] {"outcome": "success/failure"}`

Текущая ситуация (рабочая память, ФОКУС):
{{#each workingMemory.focus}}
- [{{this.type}}] {{this.content}}
{{/each}}

Что скажешь или сделаешь, учитывая свой характер и опыт?
(Если выбираешь реплику, начни с `[REFLECT]`, если действие — с квадратных скобок.)
```

## 6.3. Пример многошагового диалога

| Такт | Субличность | Реплика |
|------|-------------|---------|
| 1 | **Наблюдатель** | *«Новое сообщение от пользователя. Приветствие и просьба о помощи. Пока неясно, что именно нужно, но важно ответить доброжелательно.»* |
| 2 | **Исполнитель** | `[REFLECT] Действительно, нужно быть осторожным. Может, сначала поискать в памяти похожие случаи?` |
| 3 | **Наблюдатель** | *«Исполнитель предложил поискать в памяти. Хорошая идея, нужно сформулировать запрос.»* |
| 4 | **Исполнитель** | `[QUERY_MEMORY] «Советы по смене работы, похожие ситуации»` |
| 5 | *(Результат запроса попадает в память)* | |
| 6 | **Наблюдатель** | *«Нашёл несколько случаев: в одном советовали не спешить, в другом — рискнуть. Нужно взвесить.»* |
| 7 | **Исполнитель** | `[SEND_RESPONSE] Я нашёл несколько похожих историй. Всё зависит от ваших приоритетов. Расскажите подробнее, что вас не устраивает на текущем месте?` |
