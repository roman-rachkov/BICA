# 8. Анализ уязвимостей и механизмы защиты

| Уязвимость | Механизм защиты |
|------------|-----------------|
| **Эхо-камера** (зацикливание на внутренних состояниях) | Сенсорный якорь (reality check), мониторинг соотношения внутренних/внешних событий |
| **Когнитивная перегрузка** (переполнение рабочей памяти) | Иерархическая память, динамическое забывание, адаптивный Top-K |
| **Эмоциональная нестабильность** | Буферизация эмоций (скользящее среднее), настраиваемая реактивность |
| **Вычислительная стоимость** | Адаптивная глубина мышления, использование SLM для Наблюдателя, привычки с автоматическим выполнением, предустановленные привычки для холодного старта, сенсорный препроцессор без LLM |
| **Ригидность привычек** | Рефлексивный мониторинг, ослабление при неудачах, мета-диалог |
| **Конфликт драйверов и ценностей** | При конфликте инициируется принудительный рефлексивный диалог. Приоритет вычисляется по формуле: `priority = w1 * driveUrgency + w2 * valueAlignment - w3 * uncertainty` |
| **Дрейф личности** | Индекс дрейфа, принудительная рефлексия, учёт долгосрочных целей в обучении |
| **Потеря важных уроков при компрессии памяти** | Проверка на сильное отрицательное подкрепление перед сжатием; приоритетный анализ мета-модулем |
| **Неправильная оценка важности входящих сообщений** | Детерминированный сенсорный препроцессор с настраиваемыми правилами, исключающий субъективность |
