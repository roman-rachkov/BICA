## 9.2. Сравнительный анализ TCO (с оптимизациями и без)

**Сценарий:** 1 час работы агента в гибридном режиме (средняя частота 0.5 Гц = 1800 тактов).

**Модели:**
- Наблюдатель — Phi-3-mini (3B)
- Исполнитель — Mistral 7B

**Стоимость облачных токенов:** $0.5/1M входных, $1.5/1M выходных.

**Средняя длина:** промпт 500 токенов, ответ 100 токенов.

### Без оптимизаций

Каждый такт — полный бикамеральный цикл, привычки не сформированы:

- Вызовов LLM: 3600 (по 1800 Observer + 1800 Executor)
- Входные токены: 3600 × 500 = 1.8M → **$0.90**
- Выходные токены: 3600 × 100 = 0.36M → **$0.54**
- **Итого облако: $1.44/час**
- **Локально (RTX 3060):** амортизация $0.5 + электроэнергия $0.03 = **$0.53/час**

### С оптимизациями

80% тактов — автоматическое выполнение привычек, 20% — полный диалог:

- Тактов с LLM: 1800 × 0.2 = 360
- Вызовов: 720
- Входные токены: 720 × 500 = 0.36M → **$0.18**
- Выходные токены: 720 × 100 = 0.072M → **$0.108**
- **Итого облако: $0.288/час**
- **Локально:** $0.53/час (амортизация и энергия постоянны, но нагрузка на GPU ниже)

### Сравнение с альтернативами (для 360 вызовов)

| Решение | Цена за 1 час | Задержка | Примечания |
|---------|---------------|----------|------------|
| BICA локально (RTX 3060) | $0.53 | 0.5–2 сек | Предсказуемо, приватно |
| BICA облачно (оптимиз.) | $0.288 | 1–5 сек | Зависит от API |
| BICA облачно (без опт.) | $1.44 | 1–5 сек | Холодный старт |
| Прямые вызовы GPT-4o (360 раз) | ~$3.6 | 2–10 сек | Без внутренней мотивации |
| DeepSeek API | ~$0.3 | 2–8 сек | Дешево, но нет рефлексии |
| OpenRouter (mix) | $1–2 | var | |

**Вывод:** Локальное развёртывание BICA с оптимизациями экономически эффективно и сравнимо с бюджетными API. Облачное развёртывание имеет смысл при масштабировании, но требует предустановленных привычек для снижения стоимости холодного старта.
