# 10. Масштабирование: кластеры агентов

Для многоагентных сред вводится протокол кластеризации:

## Механизм кластеризации

| Аспект | Описание |
|--------|----------|
| **Коммуникация** | Агенты обмениваются событиями через общую шину (Redis pub/sub, MQTT) |
| **Общие драйверы** | Коллективные потребности (например, «безопасность роя») влияют на всех членов кластера |
| **Синхронизация памяти** | Обмен сжатыми воспоминаниями для коллективного обучения |

## Сценарии использования

1. **Роевой интеллект** — множество агентов решают общую задачу, обмениваясь находками
2. **Специализация** — разные агенты специализируются на разных типах задач
3. **Масштабирование нагрузки** — распределение пользовательских запросов между агентами
